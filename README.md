# 🏢 Blue Service - Sistema de Gerenciamento Empresarial

## 📌 Sobre o Projeto

O **Blue Service** é um sistema de gerenciamento desenvolvido para auxiliar uma empresa no controle de clientes, produtos, pedidos e funcionários em um ambiente centralizado e organizado.

O projeto foi desenvolvido com foco na automatização de processos administrativos, permitindo que gestores acompanhem informações importantes do negócio por meio de um painel administrativo intuitivo.

---

## 🎯 Objetivo

O objetivo do sistema é facilitar a gestão operacional da empresa, centralizando informações e reduzindo processos manuais relacionados ao controle de estoque, vendas, clientes e equipe.

---

## ⚙️ Funcionalidades

### 👥 Gestão de Funcionários

* Cadastro de funcionários
* Edição de informações
* Exclusão de registros
* Ativação e desativação de funcionários
* Listagem completa dos colaboradores

### 🧑‍💼 Gestão de Clientes

* Cadastro de clientes
* Consulta de informações
* Atualização de dados
* Gerenciamento da base de clientes

### 📦 Gestão de Produtos

* Cadastro de produtos
* Controle de estoque
* Atualização de preços
* Consulta de produtos cadastrados

### 🛒 Gestão de Pedidos

* Registro de pedidos
* Associação de produtos aos pedidos
* Consulta de histórico de pedidos
* Controle das vendas realizadas

### 📊 Dashboard Administrativo

O sistema possui um painel administrativo com indicadores importantes para auxiliar na tomada de decisão:

* Quantidade de funcionários cadastrados
* Quantidade de clientes cadastrados
* Quantidade de produtos cadastrados
* Quantidade de pedidos realizados
* Valor total em estoque
* Faturamento total
* Ranking dos produtos mais vendidos

---

## 🏗️ Arquitetura do Sistema

O projeto foi desenvolvido seguindo a arquitetura MVC (Model-View-Controller), promovendo maior organização e manutenção do código.

### Model

Responsável pela representação dos dados da aplicação.

Exemplos:

* Funcionário
* Cliente
* Produto
* Pedido

### View

Responsável pela interface apresentada ao usuário.

Tecnologias utilizadas:

* HTML
* Bootstrap
* Thymeleaf

### Controller

Responsável pelo controle das requisições e regras de negócio.

Exemplos:

* Controle de funcionários
* Controle de clientes
* Controle de produtos
* Controle de pedidos
